# Fixed-Income-Foundations
Excel demonstrations and educational materials for the Fixed Income Foundations YouTube series by Thomas Lee
Welcome to the companion materials for my YouTube educational series, Fixed Income Foundations: From Bond Basics to 
Portfolio Management.
This Repository provides Excel demonstration workbooks to help students and finance professionals understand fixed-income concepts
through practical calculations.
Excel Demonstrations
> Current Yield
> Premium and Discount Bonds
> Yield to Maturity (YTM)
> Bond pricing and Present Vlaue
> Yield Curve Anaylysis
Additional spreadsheets will be added as new episodes are released.

How to use 
1. Open folder-Demos folder.
2. Select the workbook corresponding to the episode.
3. Click Download raw file to save the Excel workbook.
4. Open it in Microsoft Excel and experiment with the input assumptions.
5. About the series introduces the terminology, mathematics, risks, and portfolio concepts used in fixed income markets.
